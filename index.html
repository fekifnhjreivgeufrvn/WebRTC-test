How To Test (No Server Needed)
  1. Device A → click HOST. An SDP offer appears in "Your SDP". Copy it.
  2. Device B → open this same page, click JOIN. An SDP offer appears. Copy it.
  3. Device A → paste Device B's SDP into "Peer SDP", click Apply Peer SDP. A new SDP (answer) appears in "Your SDP".
  4. Device B → paste Device A's new SDP into "Peer SDP", click Apply Peer SDP.
  5. Both devices should show Data Channel: open — you can now send messages and ping for RTT.

Note: This uses manual copy-paste signalling (no STUN/TURN server). Works on LAN. Internet peers may need a STUN server added.
